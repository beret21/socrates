1문제 정의

세션 복귀의 어려움

맥 리부팅(OS 업데이트 등) 후 여러 CLI 세션 중 작업하던 것을 다시 찾기 어렵다.

claude --resume <UUID>는 가능하지만 UUID 관리 수단이 없음.

설정 현황 파악의 어려움

~/.claude/와 프로젝트별 .claude/에 설정이 흩어져 있고,

하네스 엔지니어링으로 늘어난 서브에이전트/스킬 현황을 한눈에 볼 수 없다.

2해결 방향 (합의 완료)

영역결정
세션 안/soc 슬래시 커맨드로 현재 세션에 alias 부여
터미널soc 독립 명령 + claude soc ... zsh 래퍼
세션 선택fzf TUI 선택 → --resume <UUID> 클립보드 복사 (자동 실행 안 함 — --dangerously-skip-permissions 등 옵션을 직접 조합)
현황 보기터미널 요약 soc map + 정적 HTML 대시보드 soc report
구현 스택선택기: shell + fzf + jq · 분석/HTML: Python 표준 라이브러리

3기반 사실 (공식 문서 + 로컬 검증)

  • 세션 저장: ~/.claude/projects/<경로 인코딩>/<UUID>.jsonl — 각 라인에 sessionId, cwd, timestamp, gitBranch, slug(자동 별명) 포함
  • 세션 ID 획득: SKILL.md 안 ${CLAUDE_SESSION_ID} 치환 공식 지원 — docs/skills
  • 재개: claude --resume "<id>" — docs/cli-reference
  • 프로젝트 메타: ~/.claude.json의 projects 키 — lastSessionId, 비용, 모델 사용량
  • 충돌 없음: 사용자 커스텀 커맨드 부재 → /soc, soc 사용 가능
  • 주의: claude --soc 같은 커스텀 플래그는 공식 미지원 → zsh 래퍼 함수로 라우팅

5명령어 사양

/soc Claude 세션 안

사용법동작
/soc <별명> · /soc name <별명>현재 세션 UUID에 alias 기록
/soc · /soc status현재 세션 ID·alias·프로젝트, 등록 세션 수 표시

soc 터미널

명령동작
soc / soc listfzf 목록: ★ alias 세션 상단 + 최근 세션 ~50개.
Enter → --resume <UUID> 클립보드 복사 · Ctrl-Y → UUID만 복사
soc name [별명]fzf로 세션 선택 후 alias 부여/수정
soc map설정 계층(전역→Codes→Projects→프로젝트), hooks, plugins, MCP, skills/agents를 ANSI 트리로 출력
soc report~/.claude/socrates/report.html 생성 후 브라우저로 열기

zsh 래퍼

claude() {
  if [[ "$1" == "soc" ]]; then shift; soc "$@"; else command claude "$@"; fi
}

HTML 리포트 섹션

  • ① 프로젝트 × 세션 테이블 (alias 강조, --resume UUID 복사 버튼)
  • ② 설정 계층 트리 (전역 → 부모 폴더 → 프로젝트)
  • ③ 하네스 인벤토리: 에이전트 / 스킬 / 플러그인 / MCP 서버
  • ④ 비용·모델 사용량 요약
